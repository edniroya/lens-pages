「今日使えるお金」とは？

今日使えるお金とは、家賃やサブスクなどの固定費、貯金、目標をすべて確保したあとに残る、今日安心して使える金額のことです。Lensは毎朝、給料日までに出ていくお金を先に取り分け、目標に積み立て、残りを給料日までの日数で割ります。数字はその日1日固定されるので、日中に増えたり減ったりしません。

(給料日までの残高 − 固定費 − 貯金 − 目標)
÷ 給料日までの日数 = 今日の数字

  • 給料日カウントダウンと、今月のペースインジケーター。
  • 今週のチャートと、今週の要注意。崩れそうなところを先に教えます。
  • インサイトは1日1件無料。週次ブリーフィングとインサイト全件はPro。

口座連携サービスを使わない、という設計

多くの家計簿アプリは、口座連携サービス（アグリゲーター）があなたの取引履歴を預かることで自動化しています。Lensは違います。iPhoneの銀行同期はAppleのFinanceKitがWalletに接続された口座を端末の中で読み取る仕組みで、取引がLensや第三者に送られることはありません。残高アンカーと重複検出が数字を正確に保ち、引っぱって更新すれば最新に。銀行同期はProの機能です。

ご利用の前に：銀行同期はFinanceKit対応国のiPhone（iOS 17.4以降、英国の接続カードは18.4以降）でApple Walletにカードを接続している場合のみ使えます。対応国は限られており、日本国内の銀行はまだ対象外です。ただしこれは国の話で、言語の話ではありません。英国や米国など対応国で口座をお持ちなら、アプリを日本語で使いながら銀行同期も使えます。日本国内の銀行なら、月1回CSVを書き出して取り込むだけで同じ役割を果たせます。CSVインポートは全プラン無料です。

Walletから、あなたの銀行をそのまま

Apple Walletに接続したカードをLensが読み取り、取引を最新に保ちます。初回の同期では約12か月分の履歴が入ります。すべては端末の中だけで、サーバーには何も送られません。

PRIVACY

Lensはどこまでプライベート？

家計のデータは端末内のローカルデータベースに保存され、Lensがあなたのお金のクラウドデータベースを持つことはありません。登録するものがないので、ログインするものもなく、あなたのプロフィールが作られることもありません。

  • アカウント不要、登録不要、ログイン不要。
  • 広告なし。データを売ることもありません。
  • 広告識別子なし、アプリ横断のトラッキングなし。
  • 匿名のプロダクト分析は初期設定でオン。設定 → プライバシーでオフにできます。
  • Face ID・Touch ID・PINロック。ローカルのバックアップと復元。

唯一の例外

オプションのAI機能を使うと、質問と家計のスナップショットが回答のためにGoogle Geminiに送信されます。リクエストはAPIキーをサーバー側で保持するLens Cloud Function経由。AIは、あなたが何か聞かない限り動きません。

QUESTIONS

FAQ

ダウンロードの前によく聞かれることです。

銀行のログイン情報は必要？ +

いいえ。Lensが銀行のログイン情報やパスワードを求めることは一切ありません。口座連携サービス（アグリゲーター）も使いません。iPhoneの銀行同期はApple FinanceKitが端末の中で読み取る仕組みで、対応国のみの機能です。

Androidでも使える？ +

はい。LensはiPhoneとAndroidの両方で使えます。銀行同期はApple FinanceKitを使うためiPhone専用ですが、無料のCSVインポート、クイック入力、自動カテゴリ分けが同じ役割を果たします。

データは暗号化されている？ +

家計のデータは端末内のローカルデータベースに保存され、Lensがあなたの家計のクラウドデータベースを持つことはありません。アプリ自体はFace ID・Touch ID・PINでロックできます。なお、オプションのAI機能を使うと、質問と家計のスナップショットが回答のためにGoogle Geminiに送信されます。

AIには何が送られる？ +

オプションのAIに質問すると、質問の内容と家計データのスナップショットが回答のためにGoogle Geminiに送信されます。AIはProの機能で月100クレジットまで。リクエストはAPIキーをサーバー側で保持するLens Cloud Function経由です。AIを使わなければ、送信は一切ありません。

Proをやめたらどうなる？ +

データは端末に残ったまま、無料プランでそのまま使い続けられます。無料の上限（口座3件、目標3件、カテゴリ予算5件）に戻りますが、定期的な支払いは無制限のまま、毎日の数字、今月のレポート、純資産、CSVインポートも引き続き使えます。

データを書き出せる？ +

はい。Proなら取引をCSVに書き出せます。ローカルのバックアップと復元は全プランに搭載。CSVの取り込みは全プラン無料です。

料金は？ +

Lensはずっと無料で使えます。Proは月額¥800から、7日間の無料トライアル付き。月額・年額・買い切りのライフタイムがあり、価格はストアの表示が正です。

銀行同期は日本で使える？ +

銀行同期はApple FinanceKitが提供されている国・地域のiPhone（iOS 17.4以降）で利用できます。対象は国で決まるため、日本国内の銀行はまだ対象外ですが、英国や米国など対応国の口座なら日本語のままご利用いただけます。日本国内の銀行では、無料のCSVインポート、レシートスキャン（Pro）、Siriでの音声入力が自動化の主役です。

今日は、いくら使える？

明日の朝には分かります。無料、アカウント登録なし。

QUESTIONS

FAQ

ダウンロードの前によく聞かれることです。

銀行のログイン情報は必要？ +

いいえ。Lensが銀行のログイン情報やパスワードを求めることは一切ありません。口座連携サービス（アグリゲーター）も使いません。iPhoneの銀行同期はApple FinanceKitが端末の中で読み取る仕組みで、対応国のみの機能です。

Androidでも使える？ +

はい。LensはiPhoneとAndroidの両方で使えます。銀行同期はApple FinanceKitを使うためiPhone専用ですが、無料のCSVインポート、クイック入力、自動カテゴリ分けが同じ役割を果たします。

データは暗号化されている？ +

家計のデータは端末内のローカルデータベースに保存され、Lensがあなたの家計のクラウドデータベースを持つことはありません。アプリ自体はFace ID・Touch ID・PINでロックできます。なお、オプションのAI機能を使うと、質問と家計のスナップショットが回答のためにGoogle Geminiに送信されます。

AIには何が送られる？ +

オプションのAIに質問すると、質問の内容と家計データのスナップショットが回答のためにGoogle Geminiに送信されます。AIはProの機能で月100クレジットまで。リクエストはAPIキーをサーバー側で保持するLens Cloud Function経由です。AIを使わなければ、送信は一切ありません。

Proをやめたらどうなる？ +

データは端末に残ったまま、無料プランでそのまま使い続けられます。無料の上限（口座3件、目標3件、カテゴリ予算5件）に戻りますが、定期的な支払いは無制限のまま、毎日の数字、今月のレポート、純資産、CSVインポートも引き続き使えます。

データを書き出せる？ +

はい。Proなら取引をCSVに書き出せます。ローカルのバックアップと復元は全プランに搭載。CSVの取り込みは全プラン無料です。

料金は？ +

Lensはずっと無料で使えます。Proは月額¥800から、7日間の無料トライアル付き。月額・年額・買い切りのライフタイムがあり、価格はストアの表示が正です。

銀行同期は日本で使える？ +

銀行同期はApple FinanceKitが提供されている国・地域のiPhone（iOS 17.4以降）で利用できます。対象は国で決まるため、日本国内の銀行はまだ対象外ですが、英国や米国など対応国の口座なら日本語のままご利用いただけます。日本国内の銀行では、無料のCSVインポート、レシートスキャン（Pro）、Siriでの音声入力が自動化の主役です。

今日は、いくら使える？

明日の朝には分かります。無料、アカウント登録なし。
