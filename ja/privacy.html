プライバシーポリシー

最終更新日：2026年7月26日 · バージョン：1.4

このポリシーの要点をひとことで言うと：

財務データはお客様のデバイスの中にとどまります。それを預かるLensのクラウドデータベースはなく、販売することも、広告のために共有することもありません。データがスマホの外に出るのは、それが必要な機能を使うときだけです。Pro向けのAI機能（Ask AI、AIレシート解析、Proの「今日」画面に表示される週次ブリーフィング）では、質問、レシート、またはお客様自身の数字を数行にまとめたものが、Lensを経由してGoogleの有料Gemini APIに送られます。任意で使える投資のライブ価格では、ティッカーシンボルだけ（金額、数量、お客様が誰かは決して含まれません）がLensを経由して市場データサービスに送られます。銀行同期をオンにした場合、データの流れは逆向きです。Appleがすでにデバイス上に保持している銀行データを読み取るだけで、外に送るものは何もありません。詳しくは第4項、第5項、第10項をご覧ください。

2. 設計で守るプライバシー

Lensは、お客様の財務記録がLensのサーバーにコピーされないように作られています。取引、口座、目標、予算を預かるLensのクラウドデータベースは存在しません。すべてお客様のデバイス上のローカルデータベースにだけ保存され、保存中はOSが保護します（iPhoneではiOSのデータ保護、Androidではアプリ専用ストレージ）。

例外はAI機能で、それもリクエストを処理しているあいだだけです。Ask AI、AIレシート解析、週次ブリーフィングに送る内容は、Googleに届くまでの途中でLensが運用するCloud Functionを通りますが、そこに保存されることはありません。何を送り、何を保持するかは、第4項と第10項に正確に書いています。

つまり、こういうことです。

  • Lensには、お客様の取引、口座、目標、予算の記録がありません。
  • Lensはお客様の財務データを見ることができません。
  • Lensが持っていない財務記録について、提出を強制されることはありません。
  • 本アプリを削除すると、財務データも消えます（バックアップを作っていない場合）。

3. デバイス上に保存されるデータ

次のデータは、お客様のデバイス上にだけ保存されます。Lensに送られることはありません。

  • 取引（金額、日付、店名、カテゴリ、メモ）
  • 口座（名前、種類、残高）
  • 財務目標
  • 定期項目（定期的な請求と収入）
  • 月の予算
  • 投資の保有銘柄（ティッカーシンボル、数量、記録した価格）
  • お客様が作成したカスタムカテゴリ
  • 銀行同期で取り込んだ銀行の取引と残高（第5項をご覧ください）
  • アプリの設定（テーマ、言語、通貨、日付形式）

4. サードパーティのサービス

Lens自体はお客様のデータを収集しませんが、本アプリが動作するために、限られた非財務情報を処理する少数のサードパーティのサービスを使っています。

RevenueCat：サブスクリプションとアプリ内課金の管理。仮名化されたデバイスIDと、App StoreまたはGoogle Playの購入レシートを受け取ります。財務データは渡しません。氏名やメールアドレスも渡しません。

Firebase Cloud Messaging（Google）：Lensが送るプッシュ通知（通知を許可した場合）。仮名化されたデバイスの通知トークンを受け取ります。財務データは渡しません。請求のリマインダーはお客様のデバイス自身がスケジュールするもので、Firebaseは通りません。通知は初期設定ではオフです。

Google Gemini API：AIレシート解析、Ask AI、週次ブリーフィング（Pro限定）。受け取るのは、解析用のレシートのOCRテキストまたは縮小した画像データ、回答用のAsk AIの質問と財務スナップショット、または週次ブリーフィング用にその期間のお客様自身の数字を数行にまとめたもの（予算に対していくら使ったか、前の期間との比較、予算内に収まった日数、日々の支出でいちばん大きかったカテゴリ名）だけです。LensはGeminiの有料ティアを使っています。Googleは、有料のGemini APIに送られたプロンプトと応答をGoogleのモデルの学習には使わないと明言しています。

Firebase Cloud FunctionsおよびCloud Firestore（Google）：すべてのAIリクエスト（Ask AI、AIレシート解析、週次ブリーフィング）は、まずLensが運用するCloud Functionに送られます。ここでProの利用権を確認し、AIの利用回数を数えたうえで、お客様に代わってGemini APIに転送します。Gemini APIキーはサーバー側で保持しており、アプリのバイナリには入っていません。Lensは、お客様の質問、レシートのテキスト、レシート画像、Ask AIの回答を記録も保存もしません。

サーバー側で匿名サインインIDに紐づけて保持するのは、次の3つだけです。今月と今日のAI利用回数、RevenueCatから報告されるProの状態、そしてProの場合は現在の週次ブリーフィングの文面（「今日」画面を開き直すたびに作り直さないためです）。いずれにも、お客様の取引、残高、口座の詳細は含まれません。

Firebase Authentication（Google）：匿名サインイン。本アプリは氏名、メールアドレス、パスワードなしでサインインします。上のCloud FunctionがProの利用権を確認し、AIの利用回数を数えるときに、デバイスを区別できるようにするためです。このIDは、お問い合わせの際にサポートコードとして表示されるものと同じで、購入と利用回数を突き合わせるためにRevenueCatにも渡されます。個人を特定する識別子は収集しません。

Firebase Crashlytics（Google）：クラッシュレポート。リリースビルドで有効です。クラッシュのスタックトレースと、デバイスの機種名およびOSバージョンを受け取ります。取引、残高、その他の財務データは受け取りません。

Firebase App Check（Google）：Lensが運用するCloud Functionの不正利用対策です。リクエストの前に、お客様のデバイスがApple（iPhoneではApp Attest）またはGoogle（AndroidではPlay Integrity）に、本アプリが改ざんされていないことを示すトークンを求め、リクエストと一緒に送ります。トークンの検証はまだ有効にしていないため、現時点では集めているだけで強制はしておらず、これらのエンドポイントを守っているものでもありません。AIと価格取得のエンドポイントは、サインイン済みのデバイスであること、App StoreまたはGoogle Playで確認した有効なProの利用権があること、そして1日と1か月の利用上限を、すべて当社のサーバー側で適用しており、回避はできません。このトークンにはお客様に関する情報も財務データも含まれません。

Firebase Analytics（Google）：匿名の利用状況分析。初期設定ではオンで、「設定」の「プライバシー」からオフにできます。どの画面が開かれ、どこで人が離れていくかを示す、まるめた回数と決まったラベルを受け取ります。たとえば、オンボーディングのある画面が表示された、Proの画面が表示された、といった情報です。あわせて、プラットフォーム、アプリのバージョン、アプリの言語、Proかどうかも受け取ります。金額、残高、取引、口座・目標・カテゴリ・店の名前を受け取ることはなく、お客様が入力した内容を受け取ることもありません。Lensは広告識別子を取得せず、トラッキングの許可も求めず、アプリやデバイスをまたいで行動を結び付けることもしません。スイッチをオフにすると、収集はその場で止まります。

Finnhub：投資のライブ価格と銘柄検索（任意、初期設定ではオフ）。保有銘柄のフォームで銘柄を検索したとき、または投資口座でライブ価格をオンにしたときに限り、ティッカーシンボルと検索した文字だけが、Lensが運用するCloud Functionを経由してFinnhubに送られ、価格を取得します。数量、保有資産の評価額、口座名、お客様が誰かがデバイスの外に出ることはありません。Finnhub APIキーはサーバー側で保持し、Lensは価格を最長1日キャッシュするので、各シンボルの問い合わせは1日1回までです。

Yahoo Finance：同じ任意の機能の、米国外の市場向けです。こちらは本アプリがCloud Functionを通さずデバイスから直接Yahooに問い合わせるため、そのリクエストではお客様のデバイスのIPアドレスがYahooに届きます。送るのはティッカーシンボルまたは検索した文字だけです。金額、数量、お客様が誰かは送りません。

Frankfurter：欧州中央銀行が公表する参照為替レートです。複数の通貨で口座をお持ちの場合に、換算した目安を表示するために使います。本アプリは、基準通貨に対する現在のレート表をデバイスから直接取得します。金額、残高、個人データは送りません。

Google Fonts：本アプリは4種類の書体（Outfit、JetBrains Mono、Space Grotesk、Manrope）をGoogleのフォントサービスから取得しています。最初に必要になったときに取得し、その後はデバイスにキャッシュするため、新しくインストールしたときにGoogleへの通信が一度発生します。その通信に、財務データやお客様を特定する情報は含まれません。

AppleおよびGoogle：アプリの配信とアプリ内課金。iPhoneではApp Store、AndroidではGoogle Playを通じて行われ、それぞれの規約に従います。Lensが受け取るのは、サブスクリプションの利用権の状態だけです。

Lensは、広告やマーケティングの目的で、いかなるデータもサードパーティに販売、貸与、共有しません。

5. 銀行同期（Apple Wallet）

銀行同期は任意の機能で、iPhoneのみ、お客様がオンにするまで動きません。Lensが銀行につなぐ機能ではありません。Appleがすでにお客様のデバイス上に保持している銀行データを、AppleのFinanceKitを通じて読み取ります。

銀行データが本アプリに届くまでには3つのステップがあり、そのすべてをお客様が握っています。

  • AppleのWalletアプリで、お客様自身が銀行を「接続済みカード」として登録します。Lensが代わりに行うことも、始めることもできません。
  • iOSの同意画面で、お客様がLensにアクセスを許可します。
  • 利用できる口座のうち、どれを紐づけるかをお客様が選びます。紐づけた口座にはそれぞれスイッチがあり、あとからオフにできます。

有効にすると、取引と残高はWalletのデバイス内ストアからAppleのフレームワークを通って、そのままお客様のデバイス上にある本アプリのローカルデータベースに入ります。アグリゲーターも、画面のスクレイピングも、第三者の銀行データ事業者も、Lensのサーバーも、どの段階にも関わりません。銀行の認証情報をLensが目にすることはなく、接続はお客様と銀行とAppleのあいだにあります。

同期したデータは、第3項に書いたほかのデータと同じ条件でデバイス上に保存されます。紐づけた口座をオフにするか、iOSの設定でアクセスを取り消せば、それ以降の同期は止まります。

6. プッシュ通知

「設定」で請求のリマインダーやその他のプッシュ通知を有効にすると、本アプリはFirebase Cloud Messaging（Google）に仮名化されたデバイストークンを登録します。このトークンは、お客様のデバイスに通知を届けるためだけに使います。お客様が誰かや財務データとは結び付きません。

通知は初期設定ではオフです。「設定」またはデバイスの通知設定から、いつでもオフにできます。

7. 生体認証

Face ID、Touch ID、または指紋によるロックを有効にした場合、認証はすべてお使いのデバイスのOSが処理します。Lensは生体認証データにアクセスできません。本アプリがOSから受け取るのは、成功か失敗かの結果だけです。

8. バックアップと復元

バックアップ機能は、本アプリのデータをファイルにして、お客様が選んだ場所（通常はiPhoneならiCloud Drive、AndroidならGoogle Drive）に書き出します。このファイルは、お客様のデバイスと選んだストレージサービスのあいだで直接やり取りされます。Lensがバックアップのコピーを受け取ったり保存したりすることはありません。

Proの利用権の状態はバックアップに含まれません。本アプリを再インストールすると、App StoreまたはGoogle Playの購入履歴から復元されます。バックアップの安全性は、お客様が選んだクラウドストレージのアカウントの安全性に左右されます。iCloud Driveは初期設定で、保存したファイルを暗号化します。

9. CSVの読み込みと書き出し

CSVファイルはすべてお客様のデバイス上で処理されます。書き出したCSVファイルは、デバイスの共有シートから、お客様が選んだ送り先に共有されます。Lensはそのコピーを受け取りません。

10. レシートスキャン、Ask AI、週次ブリーフィング

レシートスキャンは、プランによって2つの経路で動きます。

  • デバイス上のOCR（無料プランとPro）：文字認識はすべてお客様のデバイス上で行います（iPhoneではApple Vision、AndroidではGoogle ML Kit）。この処理でデータがデバイスの外に出ることはありません。
  • AI解析（Pro限定）：複雑なレシートの場合、抽出したOCRテキストまたは縮小したレシート画像が、お客様のデバイスからLensが運用するCloud Functionに送られます。Cloud FunctionはProの利用権を確認し、月の利用回数を数えたうえで、GoogleのGemini APIに転送します。

Ask AI（Pro限定）も同じ経路です。お客様の質問と財務データのスナップショットが、同じLensが運用するCloud Functionを経由してGoogleのGemini APIに送られます。Lensはプロンプトの内容、画像データ、応答を記録しません。スナップショットに含まれるのは、質問に答えるために必要なデータだけです。

週次ブリーフィング（Pro限定）は、AI機能の中で唯一、お客様が自分で起動しないものです。Proでは「今日」画面に、週に一度、短い書き下ろしの振り返りが表示され、各月の終わりには月末版が表示されます。これを書くために、Lensはその期間のお客様自身の数字を数行にまとめたものを、同じCloud Functionを経由してGeminiに送ります。返ってきた文面は、次の期間まで匿名サインインIDに紐づけて保存されます。「今日」画面を開き直すたびに作り直さないためです。カードはその期間中、閉じておくことができます。

Proには、Ask AIとAIレシート解析を合わせて月100回、1日あたり20回までの公正利用枠が含まれます。枠は毎月1日にリセットされます。週次ブリーフィングは1期間に1回しか生成されないため、この枠には数えません。デバイス上のOCRに上限はありません。

レシート画像がLensのサーバーに保存されることはありません。コピーが残るとしても、お客様のデバイス上だけです。
